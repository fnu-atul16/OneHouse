# OneHouse

**A Java-based household expense management application for shared living.**

OneHouse is a personal software engineering project designed to help roommates manage household expenses, track individual contributions, and eventually calculate monthly settlements.

## Tech Stack

- **Language:** Java
- **Core Concepts:** Object-Oriented Programming, HashMap, Collections Framework
- **Financial Calculations:** BigDecimal
- **Date Handling:** Java Time API
- **Version Control:** Git & GitHub

## Implemented Features

- Create and manage household information
- Add, find, and remove household members
- Create and manage expense records
- Categorize expenses by type
- Calculate total recorded expenses
- Calculate expenses for a specific month
- Calculate total contributions by individual members
- Validate inputs and handle invalid operations

## Planned Features

- Monthly contribution tracking for each roommate
- Shared expense splitting and balance calculations
- Automated monthly settlement calculations
- Database persistence
- REST APIs using Spring Boot
- React-based frontend
- User authentication and authorization
- Automated testing and deployment

## Current Status

**In Development — Core Java Backend**

The project currently focuses on implementing and testing the core domain models and expense management logic.

## Future Architecture

React Frontend → Spring Boot REST API → Java Business Logic → Database

## Development Approach

OneHouse is being developed incrementally, starting with Core Java and progressing toward a full-stack application. The project emphasizes clean code, maintainability, data structures, and practical backend engineering.
